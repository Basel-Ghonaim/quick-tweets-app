### AI workflow standard:

1. The final plan is drawn up after discussion
2. We create the ticket based on the final execution plan in a text file and then create it on git hub
3. We establish the branch locally 
4. Commencement. Every operation has a commit 
5. The last commit is related to documentation. The location of the documentation will be determined after each step 
6. Push the branch to github
7. Withdraw the branch and review it 
8. Finally, merge the branch and close the ticket 
9. Move to the main branch, merge the changes, then delete the sub-branch
